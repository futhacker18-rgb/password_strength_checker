A simple python project checks the strength of a password based on different security requirements.

## Features
- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Gives a password strength score out of 5
- Provides suggestions to improve the password
- Displays Weak, Medium, Strong, or Very Strong password strength
  
  ## Technologies Used
- Python

  ## How it Works

  1. Run the Python program.
  2. Enter a password.
  3. the program checks the password based on five criteria.
  4. A score out of 5 is generated.
  5. Suggestions are provided if the password can be improved.

  ## Example

  the program checks:

  - Password length
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
